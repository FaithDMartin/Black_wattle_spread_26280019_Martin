# Black_wattle_spread_26280019_Martin
This project uses a stochastic cellular automaton (CA) implemented in MATLAB to investigate the spatial spread of black wattle (Acacia mearnsii), an invasive alien plant in South Africa. The model explores how habitat disturbance influences invasion and compares the effectiveness of different clearing strategies in reducing the final invaded area
Model Description

The model represents a simulated landscape as a 20 × 20 grid. Each cell represents 0.25 hectares, giving a total simulated landscape area of 100 hectares.

The simulation begins with four invaded cells (1 hectare) in the centre of the grid and runs for 15 time steps.

Habitat Scenarios

Three habitat disturbance scenarios are investigated:

All undisturbed habitat

30% disturbed habitat

All disturbed habitat

The probability that an uninvaded cell becomes invaded depends on its habitat type:

Undisturbed habitat: 0.10

Disturbed habitat: 0.40

An uninvaded cell can become invaded if it shares an edge with an invaded cell.

Clearing Strategies

The model compares three strategies:

No clearing: No invaded cells are deliberately removed.

One-off clearing: 50% of invaded cells are randomly removed after time step 8.

Repeated clearing: 50% of invaded cells are randomly removed after time steps 3, 6, 9, 12 and 15.

Cleared cells can become reinvaded during subsequent simulation steps if they meet the model's establishment conditions.

Simulation Procedure

Each combination of habitat scenario and clearing strategy is evaluated over 30 simulation runs. The model calculates the final invaded area in hectares for each run and summarises the results using the mean, standard deviation, minimum and maximum.

The random number generator is initialised using rng(1) to support reproducibility.

Results

The simulations indicate that:

Greater habitat disturbance is associated with a larger final invaded area.

Repeated clearing produces the smallest mean final invaded area across all three habitat scenarios.

The relative reduction achieved through repeated clearing decreases as the proportion of disturbed habitat increases.

These findings describe the behaviour of the simulated model and should not be interpreted as validated predictions of actual black wattle spread in South Africa.

Requirements

MATLAB

No additional toolboxes are intended to be required by the core simulation code.

How to Run the Model

Download or clone this repository.

Open MATLAB.

Open CA model.m.

Run the script.

Review the summary table, graphs and spatial maps generated by the code.

Limitations

The model uses illustrative establishment probabilities and has not been calibrated against field data. It does not explicitly represent long-distance seed dispersal, seed-bank dynamics, plant growth stages, regrowth after clearing, or the costs of management. Habitat disturbance is represented as a fixed spatial pattern.

Therefore, the model is intended to explore invasion scenarios and compare clearing strategies rather than to provide precise real-world forecasts.
